XR Gate with Docker on Linux

1. Download XR Gate

Use Ubuntu 24.04 (64-bit) and a CPU with AVX2 support.

Download the ZIP, extract it, and open a terminal in the docker folder. Run all commands below from that folder.

2. Install Docker

If Docker Engine 28 or newer and Docker Compose are already installed, skip this step.

sudo bash scripts/install-engine-ubuntu.sh

3. Build XR Gate

cp --no-clobber .env.example .env
chmod +x xr-gate

To choose a release, change XR_VERSION in .env. Hardware settings are in hardware/xreal_ultra.env. For another device, copy hardware/generic.env.example, fill in XR_PROFILE, XR_USB_IDS and device paths, then select the new file with XR_HARDWARE_ENV in .env. Set XR_REQUIRE_CAMERA=1 if the profile uses a camera.

Then build the image:

sudo ./xr-gate build

Wait for the build to finish. The first build needs an internet connection.

4. Start XR Gate

Connect the selected device, then run:

sudo ./xr-gate run

Follow the prompts in the console and keep it open. If the glasses are already in SBS mode, choose the current display mode when prompted.

5. Stop and start again

Stop XR Gate with Ctrl+C, or run this in another terminal:

sudo ./xr-gate stop

For the next session, run sudo ./xr-gate run again.

After reconnecting the device, stop XR Gate and start it again.

6. Optional setup

  • Gear VR and VR-PARK controllers.
  • Custom configuration.
  • To change the release: stop XR Gate, edit XR_VERSION in .env, then repeat the build and start steps.

7. If startup fails

Check the connected devices:

sudo ./xr-gate doctor

To see the running container's logs:

sudo ./xr-gate logs

XR Gate в Docker на Linux

1. Скачайте XR Gate

Нужны Ubuntu 24.04 (64 бита) и процессор с поддержкой AVX2.

Скачайте ZIP, распакуйте его и откройте терминал в папке docker. Все команды ниже выполняйте из этой папки.

2. Установите Docker

Если Docker Engine версии 28 или новее и Docker Compose уже установлены, пропустите этот шаг.

sudo bash scripts/install-engine-ubuntu.sh

3. Соберите XR Gate

cp --no-clobber .env.example .env
chmod +x xr-gate

Чтобы выбрать релиз, измените XR_VERSION в .env. Параметры оборудования находятся в hardware/xreal_ultra.env. Для другого устройства скопируйте hardware/generic.env.example, заполните XR_PROFILE, XR_USB_IDS и пути устройств, затем укажите новый файл в XR_HARDWARE_ENV в .env. Если профиль использует камеру, включите XR_REQUIRE_CAMERA=1.

Затем соберите образ:

sudo ./xr-gate build

Дождитесь завершения сборки. Для первой сборки нужен интернет.

4. Запустите XR Gate

Подключите выбранное устройство и выполните:

sudo ./xr-gate run

Следуйте подсказкам в консоли и оставьте её открытой. Если очки уже в режиме SBS, при запросе выберите текущий режим дисплея.

5. Остановите и запустите снова

Для остановки нажмите Ctrl+C или выполните в другом терминале:

sudo ./xr-gate stop

Для следующего запуска снова выполните sudo ./xr-gate run.

После переподключения устройства остановите XR Gate и запустите заново.

6. Дополнительная настройка

  • Контроллеры Gear VR и VR-PARK.
  • Свой конфиг.
  • Для смены релиза остановите XR Gate, измените XR_VERSION в .env, затем повторите сборку и запуск.

7. Если не запускается

Проверьте подключённые устройства:

sudo ./xr-gate doctor

Логи работающего контейнера:

sudo ./xr-gate logs
