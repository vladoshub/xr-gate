# Управление Monado

Monado и SteamVR используют общий модуль нормализации ввода. Физические кнопки
назначаются в конфиге backend-контроллера; аппаратных VID:PID в этом модуле нет.
Касание, направление и физический клик передаются отдельно.

Основной профиль OpenXR — Touch. Если игра не предлагает Touch-привязок,
резервный порядок по умолчанию: **Index → WMR → Vive → Simple**. Выбирается
первый профиль из этого списка, для которого игра предложила привязки.

## Настройки

При запуске через `start.sh` используется файл
`bin/drivers/monado_driver/profiles/controller_input.env`. В исходниках это
`drivers/monado_driver/profiles/controller_input.env`. Настройки общие для всех
моделей очков и контроллеров. Можно указать свой файл через
`XR_MONADO_CONTROLLER_INPUT_CONFIG=/path/to/controller_input.env`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `XR_MONADO_CONTROLLER_LEFT_AB_XY_ALIAS` | `1` | A/X и B/Y слева объединены попарно. Для четырёх независимых кнопок поставить `0`. |
| `XR_MONADO_CONTROLLER_TRACKPAD_CLICK_FROM_TOUCH` | `0` | Старый клик от любого касания/направления; включается значением `1`. |
| `XR_MONADO_CONTROLLER_AXIS_THRESHOLD` | `0.05` | Нейтральная зона осей и порог активности виртуального касания. |
| `XR_MONADO_CONTROLLER_CLICK_THRESHOLD` | `0.55` | Порог клика аналогового курка/хвата. |
| `XR_MONADO_CONTROLLER_EXPOSE_SYSTEM_BUTTON` | `1` | Передача отдельной кнопки System. Она больше не нажимает Menu в Vive/WMR. |
| `XR_MONADO_CONTROLLER_PROFILE_ORDER` | `index,wmr,vive,simple` | Порядок резервных профилей. Touch имеет приоритет, если его предложила игра. |

Порядок допускает подмножество этих четырёх имён без повторов. Например,
`wmr,vive,simple` отключает совместимость Index. Ошибочный список вызывает
предупреждение и возврат к стандартному порядку. Число физических кнопок при
выборе профиля автоматически не определяется.

Для разового запуска с четырьмя независимыми кнопками слева:

```bash
XR_MONADO_CONTROLLER_LEFT_AB_XY_ALIAS=0 bin/drivers/monado_driver/start.sh
```

Параметры читаются при создании устройств. После изменения перезапустите
Monado. При прямом запуске `monado-service` значения по умолчанию те же;
переменные можно передать окружением, а `.env`-файл нужно загрузить самостоятельно.

## Что проверить после установки

1. Запустите runtime и Monado. При касании/движении панели клик должен оставаться
   выключенным. Физическое нажатие панели включает клик; отпускание сбрасывает его.
2. Проверьте курок, хват, меню и дополнительные кнопки. В Touch слева используются
   X/Y, справа A/B. При включённом алиасе существующие A/B слева также передаются
   в X/Y. При выключенном алиасе четыре входа остаются независимыми.
3. В запасном Index-профиле проверьте кнопки, стик, панель и позы обеих рук.
   Давление хвата представлено нормализованным значением grip, давление панели —
   значением 0/1 от физического переключателя. Настоящий датчик давления, вибрация
   и скелет пальцев этим профилем не добавляются.
4. Потеря оптической позы должна сохранять валидные кнопки контроллера. Потеря
   валидного ввода должна отпускать кнопки. Перезапуск publisher должен
   переподключать поток, как прежде.

В играх с Vive/WMR-привязками действие на `/trackpad/click` требует физического
нажатия. Старый режим можно включить опцией выше; он может снова вызывать
дополнительное действие на общий клик одновременно с направлением.

## Пересборка

Изменение ввода требует пересборки и переустановки Monado один раз. Примените
исходный патч в репозитории XR Gate и выполните из его корня:

```bash
bash drivers/monado_driver/scripts/linux/install.sh
```

Используйте свои обычные параметры сборки и выбранный профиль устройства.
Также подходит стандартная CI-сборка компонента Monado. Сам runtime adapter
для этого изменения пересобирать не требуется. Запущенные игры и Monado перед
заменой бинарников закройте, затем запустите runtime, Monado и игру.

Проверки callbacks и SHM:

```bash
MONADO_DIR="$PWD/third_party/monado_driver" \
  bash drivers/monado_driver/tests/run_tests.sh
```

Это функциональные тесты реального кода драйвера с заменёнными внешними
helpers и входящими samples. Запуск игр и полноценной OpenXR-сессии проверяется
отдельно на компьютере с устройствами.
