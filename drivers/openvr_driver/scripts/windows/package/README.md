# XR Gate Windows SteamVR driver

Open **START-HERE.html** for Russian / English instructions.
Text versions: [English](WINDOWS.en.md) / [Русский](WINDOWS.ru.md).

Close SteamVR, then run **Install-Driver.bat**. Keep the registered directory in
place. Run **Test-TCP.bat** after starting XR Gate. **Direct-Mode-Guide.bat** opens
the guide and SteamVR; enabling Direct Mode is a manual step.
