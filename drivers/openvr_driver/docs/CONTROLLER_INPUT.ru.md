# Универсальное управление XR Gate в SteamVR

Windows и Linux используют одну схему виртуального контроллера. SteamVR 1.26+
выбирает штатную раскладку, которая есть у игры: сначала Oculus Touch, затем
Index, Vive и Simple Controller. Файл
`resources/input/xr_hand_controller_remapping.json` задаёт приоритеты и
преобразования. В нём нет идентификаторов игр и названий игровых действий.

## Что передаётся игре

| Вход runtime | Виртуальный контроллер |
| --- | --- |
| Trigger | Аналоговое значение, нажатие и касание курка |
| Grip | Аналоговое значение, нажатие и касание хвата |
| Thumbstick X/Y или D-pad | Координаты стика/панели и признак касания |
| Thumbstick click или D-pad centre | Физическое нажатие стика/панели |
| A/B слева | X/Y для Touch и Index; старые A/B также доступны |
| A/B справа | A/B |
| Menu | Меню приложения |

Касание, направление и нажатие передаются отдельно. Движение по панели не
создаёт нажатие её центра. В резервной Vive-раскладке направленные действия
`dpad_click` преобразуются в `dpad_touch`; параметры зоны направления сохраняются.
Обычный клик остаётся физическим нажатием. Это позволяет двигаться касанием,
не вызывая одновременно отдельное действие, назначенное на общий клик.

Панель и стик используют одни координаты runtime. Для Index-привязок давление
панели представлено значениями 0/1 от физического нажатия; настоящее давление
не измеряется. Касание кнопки берётся из runtime или из её нажатия. Изгибы
пальцев и отсутствующие физические кнопки эта совместимость не добавляет.

Поза aim/grip/handmodel в преобразованных привязках ссылается на готовую
калиброванную позу контроллера `/pose/raw`. Поэтому скрытая модель контроллера
не требует attachment-поз. Отдельные смещения aim/grip здесь не добавляются.

## Настройки

При закрытом SteamVR откройте `resources/settings/default.vrsettings` в папке
зарегистрированного драйвера. В секции `xr_tracking` доступны:

```json
"handControllerLeftABXYAlias": true,
"handControllerTrackpadClickFromTouch": false,
"handControllerInputAxisThreshold": 0.05,
"handControllerInputClickThreshold": 0.55
```

Это фрагмент существующей секции, а не весь JSON-файл. Если слева нужны четыре
независимые кнопки A/B/X/Y, выключите `handControllerLeftABXYAlias`.
`handControllerInputAxisThreshold` задаёт нейтральную зону осей и порог
активности для виртуального касания. `handControllerInputClickThreshold`
задаёт порог аналогового курка/хвата; реальный флаг нажатия также учитывается.

`handControllerTrackpadClickFromTouch: true` возвращает старое поведение для
собственных привязок Vive. Оно может снова вызывать общий клик одновременно с
направлением. По умолчанию настройка выключена.

Выбор физических кнопок, VID:PID и особенности устройства остаются в конфиге
backend-контроллера, например `override_controller.json`. Приоритеты раскладок
и сопоставление SteamVR-компонентов меняются в remapping JSON. После изменения
драйверных настроек или ресурсов перезапустите SteamVR.

## После обновления

1. Закройте SteamVR и установите пересобранный драйвер вместе с его `resources`.
   Одной замены JSON у старой DLL недостаточно.
2. Запустите runtime и SteamVR. Если у игры сохранились старые пользовательские
   привязки, выберите стандартные: сохранённая пользователем раскладка имеет
   приоритет над автоматическим преобразованием.
3. В проверке ввода SteamVR коснитесь центра, проведите по четырём направлениям,
   затем отдельно нажмите панель. Касание и направление должны работать без
   клика; физическое нажатие должно создавать клик.
4. Проверьте курок, хват, меню и обе дополнительные кнопки каждой руки. Для
   Touch-привязок левая пара — X/Y, правая — A/B.
5. В игре отдельно проверьте движение, поворот, присед, хват, меню и отпускание
   кнопок. Потеря оптической позы сама по себе не должна отключать валидный ввод
   подключённого контроллера. Потеря валидного ввода должна отпускать кнопки.

Автоматический выбор использует привязки, предоставленные игрой. Если игра
вообще не предоставляет подходящую раскладку либо требует физически
отсутствующий орган управления, понадобится собственное сопоставление.

## Сборка и проверки

Изменения общие для Windows DLL и Linux `.so`. Windows собирается MSVC/clang-cl
в существующей задаче **XR Gate split build**. Она включает
`XR_OPENVR_BUILD_TESTS` и запускает CTest до упаковки. Дополнительная задача
в **Runtime and driver functional tests** собирает Linux-драйвер и проверяет
ввод, ресурсы привязок, жизненный цикл HMD и транспорт runtime.

Новые проверки относятся к функциональности контроллера. Экспортированные
привязки конкретной игры можно дополнительно проверить командой:

```bash
python3 drivers/openvr_driver/tests/controller_bindings_test.py --bindings-zip /path/to/exports.zip
```

Эта команда проверяет наличие входов назначения и их возможностей. Она не
запускает SteamVR и не подтверждает фактическое поведение игры.
