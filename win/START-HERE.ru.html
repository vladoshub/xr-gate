XR Gate для Windows

XR Gate работает через подсистему Windows Subsystem for Linux (WSL 2). .NET уже включён в Windows-приложение.

Readme открывает эту инструкцию, Gestures — описание жестов. Документация Windows-сборки находится в docs/, изображения интерфейса — в images/.

English · Русский · Gestures · GitHub

Установите SteamVR, откройте его один раз и закройте. Распакуйте весь xr-gate-windows-wsl2-usbip.zip и запустите XR-Gate.exe. Сохраните все папки из архива рядом с программой.

Запуск

  1. Select glasses display — Подключите очки. В Windows выберите «Расширить эти экраны» и включите SBS на очках. Во вкладке Run нажмите Select glasses display и выберите номер экрана очков. Install недоступна, пока выбранный дисплей не подключён.
  2. Install — Подтвердите установку WSL, Ubuntu и XR Gate. Если появится запрос, создайте пользователя Ubuntu (см. ниже). После команды exit установка продолжится автоматически. Перезагрузка нужна только по запросу XR Gate; после неё откройте приложение для продолжения установки. После завершения Install меняется на Update.
  3. Start VR — Доступна после установки, выбора дисплея и подключения устройства. USB подключается автоматически. Stop tracking & return USB или закрытие приложения завершают сеанс, запрашивают закрытие SteamVR и возвращают устройства Windows.

Пользователь Ubuntu

В окне Ubuntu задайте своё имя пользователя Linux и пароль. При вводе пароля символы не отображаются. Когда появится командная строка Linux, введите exit; оставьте XR Gate открытым — установка продолжится автоматически. Если она остаётся на паузе, завершите создание пользователя, введите exit и нажмите Install. Перезагружайте компьютер только по явному запросу.

Вкладки

  • Run — Выбор дисплея, Install / Update, Start VR, Restart tracking, Stop, статус и Activity Log. Restart tracking перезапускает XR Gate внутри Ubuntu, сохраняя SteamVR и USB-подключение. У кнопок есть подсказки при наведении. Delete после подтверждения удаляет сохранённый дистрибутив Ubuntu со всеми его Linux-данными. Мигающие кнопки подсказывают следующий шаг.
  • Controllers — По умолчанию Gestures, Bluetooth выключен. No оставляет трекинг головы без рук и контроллеров. Для Gear VR Controllers включите Bluetooth, выберите левый и/или правый контроллер и нажмите Connect & save. Подсказки к калибровке появляются в Activity Log один раз на этап.
  • Audio — Enable по умолчанию включён; выключение отключает звук и сохраняет выбор устройств. Start VR оставляет доступный сохранённый выход Ubuntu или выбирает первый доступный. Только воспроизведение, без микрофона.
  • Settings — Hardware preset, параметры дисплея и запуска. Hotkeys: F5 запускает VR, F6 останавливает трекинг и возвращает USB, F7 перезапускает трекинг с сохранением SteamVR. Глобальные клавиши работают, пока XR Gate открыт, в том числе свёрнут; галочка сохраняется автоматически. Show command prompt по умолчанию выключен; включите перед запуском, если нужны команды калибровки в консоли.
  • Tools — Diagnostics, регистрация драйвера и проверки трекинга. List USB devices остаётся в Settings.

Bluetooth проверен на ASUS USB-BT500. Лучше использовать отдельный адаптер, чтобы системные Bluetooth-устройства оставались доступны Windows. Для встроенного MediaTek нужна поддержка в ядре WSL; смена версии Ubuntu сама по себе её не добавляет.

Пресеты находятся в hardware/*.env; Advanced settings открывает .env. Служебные скрипты PowerShell и Linux нужны приложению. Отдельные .cmd/.bat для запуска больше не поставляются.

Источник установки: Settings → URL XR Gate показывает адрес скачивания стека. Local path XR Gate имеет приоритет: выберите .tar.gz стека или папку с xr-gate-ubuntu-24.04-linux-x64.tar.gz и hand-tracking-models-mercury.tar.gz. При своём URL модели также должны лежать рядом со стеком. Нажмите Save settings, затем Install / Update.

Проблемы

  • Следуйте [Next] в Activity Log. Для диагностики используйте Tools → Diagnostics и Save log во вкладке Run.
  • Если устройство XR или Bluetooth-адаптер заняты либо не отвечают, остановите трекинг, отсоедините и снова подключите выбранные устройства, затем повторите запуск. Если камера занята Windows, закройте использующие её приложения.
  • Если после переустановки появляется ошибка старого firmware mount, закройте XR Gate и Docker, сохраните работу во всех дистрибутивах WSL, выполните wsl --shutdown в PowerShell, затем откройте XR Gate и нажмите Install. Команда останавливает все дистрибутивы WSL.
  • Если ничего не помогает, полностью выключите компьютер. Отсоедините очки и отдельный Bluetooth-адаптер, если используете его, подождите несколько секунд, подключите их обратно и включите компьютер.
