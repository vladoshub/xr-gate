XR Gate в Windows

Запуск через приложение

В заголовке приложения показаны ссылка на проект, имя из XR_DEVICE_NAME (для XREAL: Device: XREAL ULTRA) и USB-статус: CONNECTED — доступно Windows; TRACKING — передано в WSL; NOT CONNECTED — не обнаружено.

Attach USB devices можно отменить кнопкой Cancel USB operation или закрытием окна. Каждая команда usbipd ограничена 30 секундами (XR_USB_COMMAND_TIMEOUT в .env, 5–120 секунд), вся USB-операция приложения — тремя минутами. Часть устройств может оставаться подключённой после отмены: проверьте List USB devices, при необходимости переподключите выбранный адаптер и повторите. Для автоматического выбора Bluetooth по VID:PID после перезагрузки или смены порта оставьте его BUSID пустым.

Распакуйте весь Windows-архив и откройте XR-Gate.exe. .NET 10 уже включён. Сохраните скрипты и подпапки рядом с исполняемым файлом.

  1. В Settings проверьте найденный аппаратный профиль или выберите его вручную. Bluetooth и режим ввода находятся в Controllers. Идентификаторы устройств, модули, пути, геометрия и профили контроллеров задаются в hardware/*.env и .env.
  2. Нажмите Install / continue. Программа объяснит, когда нужна перезагрузка Windows, первый вход в Ubuntu или её перезапуск. Затем продолжите установку.
  3. Включите SBS и «Расширить эти экраны» в Windows. Закройте SteamVR и нажмите Select glasses display, если автоматическая идентификация недоступна.
  4. Нажмите Start VR, для консольных команд калибровки заранее включите Settings → Show command prompt. SteamVR откроется после появления актуальной валидной позы головы; лаунчер удерживает WSL работающим.
  5. Stop tracking & return USB останавливает управляемый сеанс и возвращает устройства Windows. Закрытие лаунчера также запрашивает корректную остановку.

Драйвер выбирается по текущей частоте очков. При неподдерживаемой или неизвестной частоте используется 60 Гц с предупреждением. Для однозначно определённого выхода программа проверяет и устанавливает 60 Гц, сохраняя разрешение; иначе потребуется выбрать дисплей. Основной монитор не выбирается наугад. Для ручного режима отключите XR_AUTO_DRIVER_FREQUENCY. Поиск дисплея использует сохранённый выбор, XR_DISPLAY_NAME, однозначное совпадение по XR_DISPLAY_MATCH из аппаратного профиля. Одно лишь разрешение не идентифицирует очки.

Diagnostics и Refresh status можно отменить; время ограничено 60 секундами. Для команд диагностики Linux действует лимит 10 секунд. Статус отдельно показывает настроенную частоту драйвера и текущую частоту найденного дисплея очков. Если дисплей не определён, его частота остаётся неизвестной.

Diagnostics и Save log собирают диагностику. В Run — запуск, USB и журнал; в Controllers — Bluetooth, сопряжение и режим ввода; в Audio — звук; в Tools — Diagnostics, регистрация драйвера и проверка трекинга. Workflow Launcher configuration tests публикует artifact xr-gate-windows-wsl-usbip-launcher; полная Windows-сборка кладёт лаунчер и драйверы в xr-gate-windows-wsl-usbip.zip, всегда включая запасной вариант 60 Гц.

Hardware preset читает hardware/*.env и сопоставляет XR_USB_IDS с подключёнными устройствами. Выбор вручную отключает автоопределение; Detect hardware automatically включает его снова. При нескольких совпадениях выберите профиль вручную. В Controllers режим Gestures использует оптические руки без запуска override_controller; Gear VR Controllers запускает физические контроллеры. Settings → Show command prompt по умолчанию выключен; включите до Start VR для консольных команд калибровки. Закрытие через × останавливает звук, отменяет отложенный запуск, завершает runtime и его консоль, затем возвращает USB. Неполная очистка оставляет окно открытым для повторного Stop.

Ниже остаётся инструкция для запуска командами.

1. Скачайте и подготовьте

  1. Нужны Windows 11 x64 и процессор с поддержкой AVX2.
  2. Установите Steam и SteamVR. Один раз откройте SteamVR, затем закройте его.
  3. Скачайте xr-gate-windows-wsl-usbip.zip из Releases или artifact xr-gate-windows-wsl-usbip из своего запуска CI.
  4. Распакуйте ZIP в постоянную папку. Откройте вложенную папку xr-gate-windows-wsl-usbip. Сохраните подпапки drivers, hardware, linux и windows вместе.
  5. Откройте в этой папке обычный Windows PowerShell. Все команды ниже выполняйте в нём.

Bluetooth-адаптер для WSL2

Проверенный адаптер: ASUS USB-BT500 (0b05:190e), Ubuntu 24.04 в WSL2, ядро 6.18.54.1-microsoft-standard-WSL2.

Рекомендуется использовать для XR Gate отдельный USB Bluetooth-адаптер, а системный оставить Windows. Проброс USB передаёт адаптер целиком в WSL; пока он подключён туда, Windows не может использовать его для Bluetooth-клавиатуры, мыши, наушников и других устройств. После возврата адаптера Windows снова получает к нему доступ. См. документацию usbipd для WSL.

В лаунчере включите Enable Bluetooth. Для ASUS USB-BT500 очистите Bluetooth USB BUSID и оставьте в Bluetooth VID:PID значение 0b05:190e из готового профиля XREAL. Сохраните настройки и нажмите Attach USB devices. Текущий BUSID адаптера определится автоматически, в том числе после смены USB-порта.

Для запуска скриптами укажите XR_BLUETOOTH=1 и XR_BLUETOOTH_USB_ID=0b05:190e в .env, оставив XR_BLUETOOTH_BUS_ID пустым. Также можно явно передать -BluetoothUsbId 0b05:190e. В универсальном аппаратном шаблоне VID:PID оставлен пустым для настройки другого адаптера.

Приоритет выбора: явный BUSID, явный XR_BLUETOOTH_INSTANCE_ID, настроенный VID:PID, затем сохранённый адаптер при пустых селекторах. Указанный BUSID должен существовать: незаметной подмены на выбор по VID:PID нет. Настроенный VID:PID не заменяется посторонним системным адаптером. При нескольких совпадениях используется сохранённый экземпляр с тем же VID:PID; если его нет, выберите один по BUSID. Bluetooth должен быть включён: само значение VID:PID по умолчанию не запускает проброс устройства.

Ограничение MediaTek в проверенном ядре: встроенный MT7922 (0489:e0e2) не инициализируется, поскольку в штатной конфигурации WSL 6.18.54.1 отключён CONFIG_BT_HCIBTUSB_MTK. Установка прошивок или наличие адаптера в lsusb не добавляет недостающую поддержку драйвера в ядре. Переход на дистрибутив Ubuntu 26.04 внутри WSL также её не включает. См. конфигурацию этой версии ядра. Другие адаптеры могут работать при поддержке их драйвера и прошивок текущим ядром WSL; для этой конфигурации проверен ASUS USB-BT500.

2. Настройте оборудование (Пропустите для XREAL Ultra)

Для XREAL Air 2 Ultra готовый профиль уже настроен. Один раз создайте файл своих настроек:

if (!(Test-Path .env)) { Copy-Item .env.example .env }

Для другого устройства скопируйте универсальный шаблон:

Copy-Item hardware\generic.env.example hardware\my-device.env

Отредактируйте hardware/my-device.env, затем укажите XR_HARDWARE_ENV=hardware/my-device.env в .env.

  1. Укажите профиль запуска в XR_PROFILE и имя устройства в XR_TARGET_DEVICE.
  2. Укажите VID:PID камер и IMU в XR_USB_IDS. Для ручного выбора выполните usbipd list и задайте XR_USB_BUS_IDS в .env. Для нескольких устройств разделите BUSID запятыми. Вместо них можно задать постоянные пути Windows USB instance в XR_USB_INSTANCE_IDS.
  3. При необходимости задайте Linux-пути камеры, HID, serial и устройств ввода: XR_CAMERA_DEVICE, XR_HIDRAW_DEVICES, XR_SERIAL_DEVICES, XR_INPUT_DEVICES. Если профиль использует камеру, включите XR_REQUIRE_CAMERA=1.
  4. Укажите подходящий скрипт настройки из релиза в XR_DEVICE_ACCESS_SCRIPT или оставьте поле пустым. Перечислите нужные модули Linux в XR_KERNEL_MODULES.
  5. Задайте XR_WINDOW_WIDTH, XR_WINDOW_HEIGHT, XR_RENDER_WIDTH, XR_RENDER_HEIGHT, XR_DISPLAY_FREQUENCY_HZ и оптические параметры своего дисплея.

Чтобы переопределить сохранённый выбор, укажите настройку прямо в .env. Выбирайте частоту и XR_DISPLAY_MODE (direct или extended_sbs), которые есть в архиве. Для отдельного Bluetooth-адаптера укажите его VID:PID в XR_BLUETOOTH_USB_ID для автоматического выбора либо BUSID в XR_BLUETOOTH_BUS_ID для явного выбора порта. Для отключения сохранённого донгла укажите XR_BLUETOOTH=0; для отключения Gear VR — XR_GEARVR=0. Если SteamVR не найден автоматически, задайте XR_STEAMVR_PATH.

3. Установите

  1. Дважды щёлкните INSTALL.cmd или выполните:
.\INSTALL.cmd

Для контроллеров Gear VR используйте:

.\INSTALL.cmd -GearVR
  1. Подтвердите запрос прав администратора. Перезапустите Windows и повторите ту же команду.
  2. Если Ubuntu открылась впервые, создайте имя Linux-пользователя и пароль, введите exit и повторите команду установки.
  3. Если запрошен перезапуск Ubuntu, сохраните в ней работу и выполните:
wsl --terminate Ubuntu-24.04
.\INSTALL.cmd

Если меняли XR_DISTRIBUTION, используйте указанное там имя дистрибутива. Повторите -GearVR, если использовали его.

  1. Если регистрация драйвера отложена, закройте SteamVR и выполните:
.\DRIVER.cmd

4. Выберите дисплей

Для extended_sbs:

  1. Подключите видеовход очков к видеокарте Windows и включите SBS на очках.
  2. В настройках дисплея Windows выберите Расширить эти экраны. Установите для очков разрешение и частоту из аппаратного env.
  3. Отключите прямой режим SteamVR и закройте SteamVR.
  4. Выполните:
.\DISPLAY.cmd
  1. Выберите строку очков по кнопке Определить в Windows. Чтобы закрепить имя выхода, укажите XR_DISPLAY_NAME в .env и повторите команду.

Для direct используйте Direct-Mode-Guide.bat в выбранной папке drivers/<частота>Hz-direct/xr_tracking.

5. Запустите

  1. Подключите устройства. Положите IMU-контроллеры на ровную поверхность и не двигайте их.
  2. Выполните:
.\RUN.cmd
  1. Пройдите стартовые подсказки и калибровку в открывшейся консоли. Оставьте её открытой и дождитесь SteamVR.
  2. При запросе включите дополнение XR Gate в SteamVR. Проверьте гарнитуру и запустите игру.

Для следующего сеанса подключите устройства и снова запустите RUN.cmd. После смены порта дисплея закройте SteamVR и повторите DISPLAY.cmd.

Для запуска трекинга без открытия SteamVR:

.\CONSOLE.cmd

6. Подключите контроллеры Gear VR

  1. В Controllers включите Enable Bluetooth и выберите USB-адаптер.
  2. Остановите трекинг и включите режим сопряжения на контроллерах.
  3. Нажмите Controllers → Pair Bluetooth controllers. Выберите левый и правый контроллеры по имени; MAC различает одинаковые имена. Одну сторону можно оставить Not selected, чтобы отключить её в конфиге.
  4. Нажмите Connect & save. Программа выполнит pairing, trust и connect и сохранит MAC в ~/xr-gate-wsl/config/override_controller.json. Исходный конфиг резервируется; ошибка подключения не изменяет его.
  5. Нажмите Start VR. Для штатного GearVR-профиля отдельная регистрация после этого не нужна. Register / train controllers используется для изменения кнопок и других профилей.

Скриптами та же операция предлагает выбор имён в консоли:

powershell -NoProfile -ExecutionPolicy Bypass -File .\XrGate-Wsl.ps1 -Action Pair

В Ubuntu-пакете скрипт bin/scripts/override_controller/bluetooth_controllers.py находится рядом со start_override_controller.sh. Автоматическая запись идентификаторов поддерживает backend gearvr_ble из выбранного конфига.

Звук (опционально)

  1. После обновления всего Windows-пакета один раз выполните Install / continue для настройки аудиозависимостей и доступа.
  2. Передайте USB и откройте Audio → Refresh audio devices.
  3. Выберите источник Windows и выход Ubuntu, затем нажмите Start VR. Лаунчер должен оставаться открытым.

Выбор сохраняется сразу. No audio отключает звук. Отключённое устройство остаётся в списке и используется после переподключения; другой выход автоматически не выбирается. Выход Windows может продолжать воспроизводить звук локально. Звук останавливается вместе с runtime или лаунчером. Поддерживается только воспроизведение.

7. Остановите или измените настройки

Stop tracking & return USB и закрытие окна дожидаются остановки всех процессов управляемой сессии, затем проверяют возврат USB. Это работает и после одного Attach, без запуска VR. При сбое одного detach проверяются остальные выбранные устройства. Если очистка не завершилась, окно остаётся открытым для проверки журнала и повторного Stop.

  1. Закройте SteamVR.
  2. Нажмите Ctrl+C в консоли трекинга и дождитесь остановки.
  3. Для возврата USB-устройств Windows выполните:
.\DETACH.cmd

После изменения аппаратных настроек подключите устройства и запустите снова. После смены релиза, частоты драйвера или режима дисплея в .env повторите INSTALL.cmd и настройку дисплея.

8. Если не запускается

Выполните:

.\DOCTOR.cmd

Не закрывая консоль трекинга, проверьте его:

powershell -NoProfile -ExecutionPolicy Bypass -File .\XrGate-Wsl.ps1 -Action Test

Если SteamVR сообщает о неверном дисплее рабочего стола, закройте SteamVR, проверьте расширение экранов, разрешение и частоту в Windows, затем повторите DISPLAY.cmd и RUN.cmd.

Выбор платформ в CI

В XR Gate split build → Run workflow доступны независимые переключатели Build ubuntu release и Build windows release (includes SteamVR driver). Можно собрать Ubuntu, Windows или обе платформы. Windows-пакет xr-gate-windows-wsl-usbip.zip включает WPF-приложение со встроенным .NET и SteamVR-драйверы.

При сборке только Windows установщик использует точный тег уже опубликованного Ubuntu-релиза с runtime и моделями. Повторная сборка Linux не требуется. Если подходящий релиз не найден или запрос к GitHub недоступен, Windows всё равно собирается с XR_RELEASE_TAG=latest и предупреждением. Перед установкой нужно опубликовать Ubuntu runtime с моделями или выбрать доступный тег runtime в Settings. Публикация загружает только выбранные платформы.
