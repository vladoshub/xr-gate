# XR Gate для Windows

XR Gate работает через подсистему Windows Subsystem for Linux (WSL 2). .NET уже включён в Windows-приложение.

[English](README.md) · [Русский](README.ru.md)

Установите SteamVR, откройте его один раз и закройте. Распакуйте весь xr-gate-windows-wsl-usbip.zip и запустите XR-Gate.exe. Сохраните все папки из архива рядом с программой.

## Запуск

1. **Select glasses display** — Подключите очки. В Windows выберите «Расширить эти экраны» и включите SBS на очках. Во вкладке Run нажмите Select glasses display и выберите номер экрана очков. Install недоступна, пока выбранный дисплей не подключён.
2. **Install** — Подтвердите установку WSL, Ubuntu и XR Gate. Если откроется первый вход в Ubuntu, создайте пользователя по подсказкам. Перезагрузите Windows, когда будете готовы; затем откройте XR Gate — программа предложит продолжить установку. После завершения Install меняется на Update.
3. **Start VR** — Доступна после установки, выбора дисплея и подключения устройства. USB подключается автоматически. Stop tracking & return USB или закрытие приложения завершают сеанс и возвращают устройства Windows.

## Вкладки

- **Run** — Выбор дисплея, Install / Update, Start VR, Stop, статус и Activity Log. Мигающие кнопки подсказывают следующий шаг.
- **Controllers** — По умолчанию Gestures, Bluetooth выключен. Поля сохраняются автоматически. Для Gear VR Controllers включите Bluetooth, выберите левый и/или правый контроллер и нажмите Connect & save. Подсказки к калибровке появляются в Activity Log один раз на этап.
- **Audio** — Источник звука Windows и выход Ubuntu либо No audio. Выбор сохраняется после переподключения. Только воспроизведение, без микрофона.
- **Settings** — Hardware preset, параметры дисплея и запуска. Show command prompt по умолчанию выключен; включите перед запуском, если нужны команды калибровки в консоли.
- **Tools** — Diagnostics, регистрация драйвера и проверки трекинга. List USB devices остаётся в Settings.

## Bluetooth

Bluetooth проверен на ASUS USB-BT500. Лучше использовать отдельный адаптер, чтобы системные Bluetooth-устройства оставались доступны Windows. Для встроенного MediaTek нужна поддержка в ядре WSL; смена версии Ubuntu сама по себе её не добавляет.

Пресеты находятся в hardware/*.env; Advanced settings открывает .env. Служебные скрипты PowerShell и Linux нужны приложению. Отдельные .cmd/.bat для запуска больше не поставляются.

Если запуск недоступен, следуйте [Next] в Activity Log. Для диагностики используйте Tools → Diagnostics и Save log во вкладке Run.

Для нестандартного устройства: `XR_CAMERA_DEVICE` задаёт путь камеры; `XR_CAMERA_AUTO_SELECT=1` выбирает единственную камеру по `XR_USB_IDS`. Если камера указана в самом профиле (например, пара камер), оставьте автоматический выбор выключенным.
