# XR Gate для Windows

XR Gate работает через подсистему Windows Subsystem for Linux (WSL 2). .NET уже включён в Windows-приложение.

[English](README.md) · [Русский](README.ru.md)

Установите SteamVR, откройте его один раз и закройте. Скачайте и распакуйте из 'Releases' https://github.com/vladoshub/xr-gate/releases/latest весь xr-gate-windows-wsl2-usbip.zip и запустите XR-Gate.exe. Сохраните все папки из архива рядом с программой.

## Запуск

1. **Hardware preset** — Изначально устройство не выбрано. Подключите поддерживаемое устройство для автоматического распознавания и сохранения либо выберите пресет в Settings. Ручной выбор тоже сохраняется. Install / Update доступны после выбора пресета.
2. **Install** — Подтвердите установку WSL, Ubuntu и XR Gate. Подключённый дисплей не требуется. Для выбранного устройства ставится SBS-драйвер 60 Hz, а если его нет — минимальная доступная частота SBS. При необходимости создайте пользователя Ubuntu; после `exit` установка продолжится автоматически. Перезагрузка нужна только по запросу. После завершения Install меняется на Update.
3. **Select glasses display** — Перед запуском VR подключите устройство, включите SBS и «Расширить эти экраны» в Windows. Однозначно найденный дисплей выбирается автоматически. Иначе кнопка активируется и мигает — выберите экран очков вручную. Без подключённого поддерживаемого устройства кнопка недоступна.
4. **Start VR** — Доступна после установки, выбора дисплея и подключения устройства. USB подключается автоматически. Stop tracking & return USB или закрытие приложения завершают сеанс, запрашивают закрытие SteamVR и возвращают устройства Windows.

## Определение дисплея и SBS

Для Air 2 Ultra должны одновременно совпасть код модели EDID `MRG3136` и имя EDID `Air 2 Ultra`. Проверка применяется и к сохранённому/ручному выбору дисплея. В других профилях можно задать `XR_DISPLAY_MODEL_ID` и `XR_DISPLAY_MODEL_NAME`: должны выполняться все заданные условия. Для профилей без этих точных условий остаётся `XR_DISPLAY_MATCH`. Код модели не является серийным номером; указанные значения получены с Air 2 Ultra и могут отличаться у другой ревизии или прошивки.

Необязательная настройка профиля `SBS_RESOLUTION=3840x1080` задаёт требуемое текущее разрешение экрана Windows. При другом известном разрешении после названия устройства появляется **(SBS OFF)**, а Start VR/F5 недоступны. При совпадении разрешения подпись исчезает. Если экран отсутствует или его разрешение неизвестно, запуск также недоступен, но SBS OFF не показывается. Скрипт повторяет проверку перед запуском трекинга и непосредственно перед запуском SteamVR. Install и трекинг без SteamVR доступны независимо от SBS. Если `SBS_RESOLUTION` отсутствует или пустая, устройство считается работающим в одном режиме; дополнительной проверки и подписи SBS нет. Для других устройств укажите их требуемое `ШИРИНАxВЫСОТА`.

## Защита экрана очков

Settings → **Protect device display during tracking** включена по умолчанию и сохраняется автоматически. Пока XR Gate запускает трекинг или отслеживает устройство, курсор остаётся на обычных мониторах, а попавшие на выбранный экран очков окна возвращаются на рабочий монитор. После Stop, обнаружения завершения трекинга, выключения галочки или закрытия лаунчера экран снова доступен. Просто открытый лаунчер экран не блокирует.

Защита применяется к отдельному второму экрану в extended SBS. Основной монитор и окно вывода SteamVR исключены. Разрешение, частота и расположение экранов не меняются. Это защита рабочего стола: исключительный полноэкранный режим и окна приложений с повышенными правами могут её обойти. Если SteamVR сбоит при разворачивании окна на другом мониторе, для выяснения причины нужны `vrcompositor.txt` и `vrserver.txt`.

## Пользователь Ubuntu

В окне Ubuntu задайте своё имя пользователя Linux и пароль. При вводе пароля символы не отображаются. Когда появится командная строка Linux, введите `exit`; оставьте XR Gate открытым — установка продолжится автоматически. Если она остаётся на паузе, завершите создание пользователя, введите `exit` и нажмите Install. Перезагружайте компьютер только по явному запросу.

## Вкладки

- **Run** — Выбор дисплея, Install / Update, Start VR, Restart tracking, Stop, статус и Activity Log. Restart tracking сохраняет SteamVR и USB-подключение. Delete после подтверждения удаляет сохранённый Ubuntu, его Linux-данные и установленные копии драйверов из служебного каталога XR Gate. Регистрации драйверов из других каталогов сохраняются. Мигающие кнопки подсказывают следующий шаг.
- **Controllers** — По умолчанию Gestures, Bluetooth выключен. No оставляет трекинг головы без рук и контроллеров. Поля сохраняются автоматически. Для Gear VR Controllers включите Bluetooth, выберите левый и/или правый контроллер и нажмите Connect & save. Подсказки к калибровке появляются в Activity Log один раз на этап.
- **Audio** — Enable по умолчанию включён; выключение отключает звук и сохраняет выбор устройств. Start VR оставляет доступный сохранённый выход Ubuntu или выбирает первый доступный. Только воспроизведение, без микрофона.
- **Settings** — Hardware preset, параметры дисплея и запуска. Save settings находится по центру нижней панели. Hotkeys: F5 запускает VR, F6 останавливает трекинг и возвращает USB, F7 перезапускает трекинг с сохранением SteamVR. Глобальные клавиши работают, пока XR Gate открыт, в том числе свёрнут; галочка сохраняется автоматически. Show command prompt по умолчанию выключен; включите перед запуском, если нужны команды калибровки в консоли.
- **Tools** — Diagnostics, регистрация драйвера и проверки трекинга. List USB devices остаётся в Settings.

**Источник установки:** Settings → URL XR Gate показывает адрес скачивания стека. Local path XR Gate имеет приоритет: выберите `.tar.gz` стека или папку с `xr-gate-ubuntu-24.04-linux-x64.tar.gz` и `hand-tracking-models-mercury.tar.gz`. При своём URL архив моделей также должен лежать рядом со стеком. Нажмите Save settings, затем Install / Update.

## Bluetooth

Bluetooth проверен на ASUS USB-BT500. Лучше использовать отдельный адаптер, чтобы системные Bluetooth-устройства оставались доступны Windows. Для встроенного MediaTek нужна поддержка в ядре WSL; смена версии Ubuntu сама по себе её не добавляет.

Пресеты находятся в hardware/*.env; Advanced settings открывает .env. Служебные скрипты PowerShell и Linux нужны приложению. Отдельные .cmd/.bat для запуска больше не поставляются.

## Проблемы

- Следуйте [Next] в Activity Log. Для диагностики используйте Tools → Diagnostics и Save log во вкладке Run.
- Если устройство XR или Bluetooth-адаптер заняты либо не отвечают, остановите трекинг, отсоедините и снова подключите выбранные устройства, затем повторите запуск. Если камера занята Windows, закройте использующие её приложения.
- Если после переустановки появляется ошибка старого firmware mount, закройте XR Gate и Docker, сохраните работу во всех дистрибутивах WSL, выполните `wsl --shutdown` в PowerShell, затем откройте XR Gate и нажмите Install. Команда останавливает все дистрибутивы WSL.
- Если ничего не помогает, полностью выключите компьютер. Отсоедините очки и отдельный Bluetooth-адаптер, если используете его, подождите несколько секунд, подключите их обратно и включите компьютер.

Для нестандартного устройства: `XR_CAMERA_DEVICE` задаёт путь камеры; `XR_CAMERA_AUTO_SELECT=1` выбирает единственную камеру по `XR_USB_IDS`. Если камера указана в самом профиле (например, пара камер), оставьте автоматический выбор выключенным.

Пакеты SteamVR находятся в `drivers/<XR_TARGET_DEVICE>/<Hz>Hz-<mode>/xr_tracking`. Устройство берётся из активного Hardware preset; частота и режим выбираются внутри этой папки. Резервные 60 Гц также относятся только к выбранному устройству.
